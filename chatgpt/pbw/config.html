Codex

Send messages to Codex sessions on your computers, and start or follow up Codex Cloud tasks.

Your computer needs Codex remote control turned on: in the Codex app, or with codex remote-control start.

1. Copy this link and open it in your phone's browser. Sign in when asked (OpenAI asks again even if you are signed in).

2. The browser ends on a page that won't load, at an address starting with http://localhost:1455. Copy that whole address and paste it here.

    Pair each computer with this phone once. On the computer, open the Codex app's remote control (Settings → Connections) or run codex remote-control pair, then paste the code it shows (or the QR code's text).
