# Complication Face (Plugin Demo)

Demo watchface for the plugin API: the time and date with two slots, a number and a bitmap, filled
from the user's preferred readings (`preferences/complications`). Each slot takes the first reading
offering its shape that the other hasn't taken. Needs the Pebble SDK to build; see the
[repository README](../README.md#building).

## Functions

None. It only reads other plugins' sources.
