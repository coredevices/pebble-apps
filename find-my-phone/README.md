# Find My Phone

One-click watchapp that rings the phone, even on silent. Pick it in the launcher: the phone rings for up to a minute and the watch goes straight back to the watchface, and the launcher row shows when it last rang. If the phone can't be reached, the app stays open and says why.

It calls the app's built-in Find My Phone `ring` action, which needs the `FindMyPhone` permission. Build: see the [repository README](../README.md#building) (needs the Pebble SDK).
