Workflowy

Send notes and todos from your Pebble to your Workflowy outline.

  1. Tap Get API key. Workflowy's API key page opens in your browser.
  2. Sign in to Workflowy if it asks, and create a key if you don't have one yet.
  3. Copy the key, come back here, paste it below and tap Save & check key.

The key is kept in this plugin's private settings on this phone. Leave it blank later to keep the saved key.

Todos with a date go on their day in the Workflowy calendar. Workflowy doesn't send alerts. To use one of your own places, add it as a shortcut in Workflowy, then reopen this page.
